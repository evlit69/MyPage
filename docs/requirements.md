# Functional Requirements

- User registration by email, username and password
- Username and password validation
- Users can login/logout
- Personal page with: name, username, profile picture, description, occupation, social media links, skills, achievements
- Personal page editing and customization
- Button to share personal page
- Users can access their own editing interface only after authentication

# Non-functional requirements
- Passwords must be securely hashed before storage
- XSS protection
- SQL injection protection
- Input validation
- Clean and intuitive user interface
- Responsive design for desktop and mobile devices
- User data must be preserved after page reloads
- Changes to personal pages must be saved persistently

# Out of Scope:
- Email verification
- Payments
- Comments
- Password, email, username changing
